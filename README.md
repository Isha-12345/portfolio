# Isha Adhikari — Portfolio

A single-page portfolio built with plain HTML, CSS, and JavaScript, showcasing my machine learning, deep learning, big data, NLP, and LLM-agent projects.

**Live site:** _add your GitHub Pages URL here after enabling Pages_

## Tech

No frameworks, no build step — one self-contained `index.html`. Fonts loaded from Google Fonts; motion respects `prefers-reduced-motion`; responsive down to mobile.

## Run locally

Just open `index.html` in a browser, or serve it:

```bash
python -m http.server 8000
# then visit http://localhost:8000
```

## Deploy (GitHub Pages)

1. Push this repo to GitHub.
2. Repo **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
3. Branch: `main`, folder: `/ (root)` → **Save**.
4. The site goes live at `https://<username>.github.io/<repo>/` within a minute or two.
